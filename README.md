# Kelvin Portfolio — WordPress Theme

Кастомная тема для WordPress, разработанная с нуля на основе дизайн-макета портфолио фрилансера. Тема полностью адаптивна и готова к использованию на реальных проектах.

## ✨ Особенности

*   **Адаптивная верстка:** Корректное отображение на ПК, планшетах и мобильных устройствах (Mobile First).
*   **Интерактивность:** Реализовано кастомное бургер-меню на чистом JavaScript (без использования плагинов).
*   **Анимации:** Плавное появление элементов при скролле с помощью библиотеки AOS (Animate On Scroll).
*   **Структура:** Готовые секции для портфолио: Услуги (Services), Проекты (Portfolio), Контакты (Contacts).
*   **Стандарты WordPress:** Правильное подключение стилей и скриптов через `wp_enqueue_scripts` (без хардкода в шаблонах).

## 🛠 Используемые технологии

*   **Backend:** PHP, WordPress API
*   **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
*   **Библиотеки:** AOS (Animate On Scroll)
*   **Инструменты:** Git, GitHub
