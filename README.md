# Kelvin Portfolio — WordPress Theme

Кастомная тема для WordPress, созданная на основе макета портфолио фрилансера.

## Особенности:
- Адаптивная верстка (корректно отображается на ПК, планшетах и мобильных устройствах).
- Бургер-меню на мобильных устройствах.
- Плавные анимации при скролле (библиотека AOS).
- Разделы: Услуги (Services), Портфолио (Portfolio), Контакты (Contacts).

## Как установить:
1. Скачайте архив с темой.
2. Перейдите в админку WordPress → Внешний вид → Темы → Добавить новую → Загрузить тему.
3. Загрузите архив и активируйте тему.

## Используемые технологии:
- HTML5, CSS3, PHP, JavaScript
- WordPress
- AOS (Animate On Scroll)
